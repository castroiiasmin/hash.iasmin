Entendendo Hash

Descubra como uma palavra pode ser transformada em um número e como palavras diferentes podem gerar exatamente o mesmo valor.

Começar desafio ↓

def calcula_hash (senha):

valor = 0

for letra in senha:

valor += ord(letra)

return valor

COMO FUNCIONA?

Uma função simples, um conceito importante.

Nesta atividade, usamos a soma dos valores ASCII de cada caractere para criar um valor de hash.

CONCLUSÃO

Nem todo hash simples é seguro.

Este exemplo é educativo. Como ele apenas soma valores ASCII, diferentes palavras podem produzir o mesmo resultado.

Algoritmos de hash utilizados em aplicações reais são muito mais complexos e possuem propriedades de segurança específicas.
